O que é o VitalKey?

O VitalKey é um sistema revolucionário que salva vidas através do acesso rápido a informações médicas críticas. Em emergências, profissionais de saúde (SAMU, bombeiros, hospitais) podem ler uma tag NFC que redireciona para uma página web com os dados essenciais de um paciente.
